# Depth First Search 

## Explores as deep as possible befor backtracking 
## Works on graphs and trees usually uses stack (explicit) or recursion (implicit stack)

## Common DFS patterns
- Connected components
- Path existence
- Cycle detection
- Topological sorting
- Tree properties (height, subtree size)
- Grid problems (islands, regions)


### Core Idea of Recusion btw, 
Recursion is stack-based (LIFO).
BFS needs queue-based (FIFO) behavior.
